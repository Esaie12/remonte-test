#RT-018 Bloqué Critique Site e-commerce

Le bouton "Commander" ne fonctionne pas sur mobile

Remontée par Sophie Martin Il y a 2 heures iPhone 14 · Safari 17 Page : /cart/checkout
Description du retour

Lors de mon test sur iPhone 14 avec Safari, j'ai constaté que le bouton "Commander" sur la page de récapitulatif du panier ne réagit pas au clic.

Voici les étapes pour reproduire le problème :

  1. Ouvrir le site sur Safari (iOS 17.4)
  2. Ajouter un article au panier
  3. Accéder à la page de récapitulatif (/cart/checkout)
  4. Appuyer sur le bouton "Commander"

Résultat attendu : Redirection vers la page de paiement.
Résultat obtenu : Rien ne se passe. Le bouton semble inactif.

Le problème ne se reproduit pas sur Chrome mobile ni sur Desktop.

Ce problème est bloquant pour la recette finale prévue vendredi.
